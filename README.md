# Interactive Portfolio Website UI

An interactive **portfolio-style website UI** built to practice advanced frontend interactions and JavaScript state management.  
This project focuses on UI behavior, customization features, and responsive user experience rather than personal branding.

## 🚀 Live Demo
🔗 https://rowenahassan.github.io/portfolio-website/

## 🛠️ Built With
- HTML5  
- CSS3  
- Tailwind CSS  
- JavaScript (Vanilla JS)

## ✨ Features
- Dark / Light mode toggle with persistent state
- Scroll-to-top button with smooth navigation
- Portfolio filtering using tabs
- Fully responsive testimonials carousel (custom JavaScript logic)
- Interactive settings sidebar
- Font switcher with saved preferences
- Dynamic theme color selection
- CSS variables controlled via JavaScript
- All user settings saved using **localStorage**

## 🧠 JavaScript Concepts Applied
- DOM manipulation
- Event handling
- State persistence using localStorage
- Responsive behavior handling
- Custom carousel logic
- Dynamic class and style updates
- Working with arrays and objects
- UI state management without frameworks

## 🎯 Purpose
This project was built to:
- Practice building interactive UI components
- Apply JavaScript logic to real-world frontend scenarios
- Improve understanding of UI state management
- Create a reusable portfolio-style layout for design concepts

> ⚠️ Note: This project is a **UI/UX design concept** and not a real personal portfolio.
